# Historical notes

One-off reports and session write-ups kept for provenance. They are **snapshots, not
current documentation** — several describe behaviour that has since been corrected (most
notably the Indurent Park numbers, which were measured on the wrong surface until 8 Sep 2026).

Current documentation lives at the repo root:
- `README.md` — what the system is and how to run it
- `CLAUDE.md` — the session rules, every one of which exists because a session got it wrong
- `DEPLOY.md` — deploy procedure and the pre-flight checks
- `ROBUSTNESS_REPORT.md` — generated by `robustness_tests.py`, not hand-written
